# POO-Crear-objetos-con-sin-Scanner
Este repositorio contiene una serie de ejercicios desarrollados en Java con el objetivo de aplicar los fundamentos de la Programación Orientada a Objetos (POO), como el uso de clases, objetos, métodos con return, encapsulamiento y validaciones.
Conceptos aplicados
Clases y objetos
Métodos con return
Encapsulamiento
Validaciones con set
Uso de Scanner
Lógica condicional (if
Este proyecto fue desarrollado con fines educativos para reforzar conceptos básicos de Java
